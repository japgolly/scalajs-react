# 4.1.1

* Fix `EffectCallback.callbackOption.dispatch` which previously didn't run the given callback.
* Fix rate-limiting in `AsyncCallback` which previously didn't run the failure callback.
* Fix `CallbackCatsEffect.syncCallback.onCancel` not to run the finaliser because callbacks are uncancelable.
* Fix `Callback.ResultGuard` in Scala 3 not rejecting `() => A` and `js.Function0[A]`
* Fix `AsyncCallback.logAround` to use sequential instead of parallel operators
* Fix `AsyncCallback.debounce` which swallowed failures and hanged forever when `f(a)` failed
* Fix `AsyncCallback.sync` to re-throw failures
* Fix `AsyncCallback.memo()` when self fails synchronously
* Fix case of `AsyncCallback.Barrier.isComplete` returning `false` when complete
