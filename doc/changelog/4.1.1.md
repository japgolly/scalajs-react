# 4.1.1

* Add extra safety to `EffectCallback` and `EffectCatsEffect` by deferring evaluation of by-name args
* Delete unused `CurrentColor` class from styles
* Delete unused `VdomBuilder.ToVdomElement`
* Fix `aria.rowCount` to accept an `Int` instead of a `String`
* Fix `AsyncCallback.debounce` which swallowed failures and hanged forever when `f(a)` failed
* Fix `AsyncCallback.flatMap` and `.map` still evaluating its function after cancellation
* Fix `AsyncCallback.handleError` and `.maybeHandleError` not catching synchronous exceptions thrown by the recovery function or checking for cancellation
* Fix `AsyncCallback.logAround` to use sequential instead of parallel operators
* Fix `AsyncCallback.memo()` when self fails synchronously
* Fix `AsyncCallback.onCancel` not unregistering its finaliser when the callback fails
* Fix `AsyncCallback.sync` to re-throw failures
* Fix `AsyncCallback.traverse_` (and `sequence_` / `awaitAll`) not propagating cancellation state across tasks and overwriting earlier errors with later ones
* Fix `AsyncCallbackToIO` not marking the `AsyncCallback` state as cancelled or running `onCancel` finalisers
* Fix `Callback.ResultGuard` in Scala 3 not rejecting `() => A` and `js.Function0[A]`
* Fix `CallbackCats.callbackCatsMonadAsyncCallback` so `ap`, `ap2`, and `map2` execute sequentially rather than in parallel
* Fix `CallbackCatsEffect.syncCallback.onCancel` not to run the finaliser because callbacks are uncancelable
* Fix `CallbackOption.{traverse,sequence}_` missing in Scala 3
* Fix `CallbackOption.{when,unless}` in Scala 3 not being by-name
* Fix `CallbackTo.future` in Scala 3 not being by-name
* Fix `EffectCallback.callbackOption.dispatch` which previously didn't run the given callback
* Fix `onAuxClickCapture` to be a mouse event
* Fix `SyncPromise.complete` to run all remaining callbacks even if an earlier one throws an exception
* Fix `TagMod.when` and `TagMod.unless` in Scala 3 evaluating its `TagMod` eagerly
* Fix case of `AsyncCallback.Barrier.isComplete` returning `false` when complete
* Fix case of `AsyncCallback.cancel` cancelling prematurely before execution and not running `onCancel` finalisers
* Fix rate-limiting in `AsyncCallback` which previously didn't run the failure callback
* Handle `null` in `CallbackTo.windowOpen`
