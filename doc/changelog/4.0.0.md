# React v19

scalajs-react now supports the following new features in React v19:

* New hook: `useActionState`

* New hook: `useFormStatus`

* New hook: `useOptimistic`

* New hook: `useEffectEvent`

* Hook `useTransition`: `startTransition` now accepts async callbacks

* Add `React.use(Promise[A] | Context[A]): A`

* Add `ReactDOM.requestFormReset`

* Add `.withCleanup` to the vdom `untypedRef` attribute that accepts a clean-up function

* `ReactOptions.{Create,Hydrate}Root` now has `withOnCaughtError` and `withOnUncaughtError` options.

* HTML attributes: `action` and `formAction` now take a String, a synchronous callback, or an asynchronous callback.
  The callback syntax is to use `-->` or `==>` just like event-handler attributes.

* New HTML attribute: `precedence` which takes a String

* Add `ReactDOM.prefetchDNS`
* Add `ReactDOM.preconnect`
* Add `ReactDOM.preload`
* Add `ReactDOM.preinit`

* Add `Context.apply` as an equivalent alternative to `Context.provide` which will be deprecated in future

* Add `React.Activity`

# Other

* Delete all deprecated code — ensure you update to 3.0.0 and resolve deprecation warnings before upgrading to 4.0.0
* Upgrade Cats Effect to 3.7.0
