# 4.1.0

* Add support for React 19.3
  * Add `React.ViewTransition` and `Ref.toViewTransition`
  * Add `React.addTransitionType`
  * Add `React.Fragment.withRef`, `React.Fragment.withKeyAndRef`, and `Ref.toFragment`
  * Add new HTML attribute: `onFullscreenChange`
  * Add new HTML attribute: `onFullscreenError`
  * Add new SVG attribute: `maskType`

* Upgrade Scala 3 to 3.3.8
* Upgrade cats-effect to 3.7.1
